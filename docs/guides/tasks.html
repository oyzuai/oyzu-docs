Run native tasks

Use Oyzu to discover tasks exposed by your project and then invoke them through one consistent command surface.

List tasks​

oyzu run list

The result reflects your project's native manifests, supported tooling and any explicit task configuration.

Run a task​

oyzu run <task-name>

Replace <task-name> with a name returned by run list. Do not type the angle brackets. The selected task can have native hooks and dependencies that affect its execution.

Inspect details​

oyzu run --help
oyzu --json run list

See build tasks for hook order, native output streams, failures and execution effects. Use CLI output to understand structured results.

Task names depend on project discovery

There is no universal list of run task names that works in every repository. Start with the actual task inventory rather than copying a guessed task.
