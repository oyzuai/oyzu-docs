Ecosystem support

CLI reference

Published from the canonical docs/reference/ecosystem-support.md file. Features marked experimental remain experimental; check support limitations before relying on them.

Use this page to see what Oyzu builds today, which reports it produces, and where each build runs. Oyzu is experimental. Support is for the project shapes and platforms listed here. A language or tool not listed on this page isn't supported yet, and neither is an unlisted combination.

Where builds run​

  • Native builds run on your machine with the tools Oyzu installs for you. They have your account's access to files and the network. See native local builds.
  • Isolated builds (oyzu build --isolated) run in a Linux container. They need Docker, collect dependencies first, and then build offline. The container is Linux (amd64). The host can be Linux or Windows (x86-64).

Plain oyzu build is native when every selected target has a native build, and isolated otherwise. See which builds are native.

Node profiles and their maturity​

The right Node setup depends on the package manager and the project shape. This table shows what works for each combination.

Project shapenpmpnpmYarn Classic 1.22.22Yarn Berry 4.17.1
Single-root application (a dist/ directory, Node test runner reports)Native and isolatedNative and isolated (pnpm 10.11.0 only in isolated builds)Native and isolatedNative and isolated. node-modules linker only
Single-root package (.tgz)Native and isolatedIsolated, for projects with no dependenciesNot supported yetNot supported yet
Workspace packages (several .tgz files)Native and isolatedIsolatedNativeNative
Workspace applicationIsolated, with a private rootNot supported yetNot supported yetNot supported yet
  • Native Node builds are supported on Linux and Windows (x86-64), except where noted. Isolated builds use a Linux (amd64) container.
  • A native npm single-root package is built when you declare it explicitly with uses: node/app. Native workspace packages: npm on Windows (plus TypeScript workspaces on Linux), Yarn Classic on Linux, Yarn Berry on Windows.
  • Yarn Plug'n'Play, Yarn workspaces in isolated builds and per-member application artifacts aren't supported.
  • See npm workspaces, pnpm and Yarn for workspace details.
  • oyzu run test can run workspace tests for npm, pnpm 10 and Yarn Classic on Windows. Dependencies must already be installed. See workspace tests.

Test frameworks and Vite​

The Node test runner is supported in the shapes above. These also work for npm applications:

ToolSupport
Vitest 5.0.3 with V8 coverageNative builds on Linux and Windows. Isolated builds and workspaces aren't supported yet
Jest 29.7.0Native builds on Linux and Windows. Isolated builds and workspaces aren't supported yet
Mocha 12.0.3 with c8Native builds on Linux and Windows. See Mocha
Vite 8.3.3 applicationNative builds on Windows, and isolated builds. SSR, library mode and watch mode aren't supported

Reports and linting for Node projects are described in Node quality checks, direct tests and Node applications.

Not supported​

  • CMake and C/C++ builds, SwiftPM, Xcode and Android aren't supported. You can run their tools with oyzu exec or a task, but Oyzu doesn't discover those projects, collect their artifacts or check their reports.
  • Windows ARM64 and macOS Apple silicon hosts aren't supported. On Windows, Oyzu doesn't run Windows containers or use Windows SDKs for isolated builds.
