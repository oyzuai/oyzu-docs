oyzu scan

Run the scanners your configuration or organization policy selects (Gitleaks, Trivy, Grype or SonarQube) against the exact source and artifacts a successful build recorded in dist/. scan doesn't rebuild, run tests or publish. It reads the build manifest's recorded source selection and scans that.

oyzu scan [OPTIONS]

Note: Experimental. Native Gitleaks scanning works on Windows; other scanners and project layouts have more limited support. See the scan reference.

Options​

OptionDescription
--offlineUse local inputs and tools only; download and analyze nothing online
--store <DIR>Use this tool store instead of the shared user store

The global options also apply.

Select a scanner​

scan works on an existing build's inputs, so run oyzu build first. With no scanner selected, it stops before doing anything:

$ oyzu scan --offline
✗ SCAN_SELECTION_REQUIRED: no scanner selected; add [scan.gitleaks] with enabled = true to oyzu.toml

Turn on Gitleaks for the project in oyzu.toml:

[scan.gitleaks]
enabled = true
failOnFindings = true   # optional: any finding fails the scan

Oyzu installs Gitleaks through its tool store like any other tool (a [tools] entry for it wins when present), without editing oyzu.lock. Other scanners and SonarQube are selected by organization policy (scan.policy), which a project file can't set.

Then run:

oyzu scan

Each run is recorded under .oyzu/scans/<run-id>/ (manifest.json, plan.json, events.jsonl and each scanner's report). The output shows a Preflight phase, a Scan phase and a final table with each scanner, subject, result and duration.

Exit status​

StatusWhen
0Every selected check ran and the result is accepted
1A scanner failed to run, the result was rejected (for example, a finding with failOnFindings), no scanner is selected, or the recorded source doesn't match (SCAN_SOURCE_MISMATCH)
2Invalid arguments
3Invalid configuration or policy

Common errors​

CodeFix
SCAN_SELECTION_REQUIREDEnable a scanner, such as [scan.gitleaks] enabled = true.
SCAN_SOURCE_MISMATCHThe source changed since the build. Build again, then scan.
SCAN_SOURCE_SELECTION_INVALIDFiles that affect source selection changed after the build (for example, a new Cargo workspace member or a release file that was ignored). Fix the source or workspace membership, build again, then scan.
TOOL_OFFLINE--offline and a scanner image isn't available locally. Run once online.
SCAN_OFFLINESonarQube is selected and --offline is set. SonarQube needs the network.

Checks are never skipped to make an offline run pass.
