oyzu inspect and oyzu history

Two read-only commands for looking at builds after they ran. oyzu inspect checks a build's output: every file in the bundle must match the digest the build recorded. oyzu history lists the builds Oyzu keeps and summarizes one of them. Neither runs project code.

oyzu inspect​

oyzu inspect [OPTIONS] [BUNDLE]
ArgumentMeaning
[BUNDLE]Bundle directory or OCI archive; defaults to the project's bundle directory (dist/)

A bundle is the directory oyzu build writes (dist/ by default: manifest, plan, reports and artifacts), or an exported OCI image archive (.tar). With no argument, Oyzu uses the project's build.bundleDirectory. A bundle path you name is inspected directly, without opening project configuration.

OptionDescription
--provenance <FILE>Saved standard Sigstore v0.3 SLSA provenance bundle
--release-profile <FILE>Your expected GitHub workflow and source, as an independent profile file
--artifact <PATH>Recorded file path inside an Oyzu bundle directory
--trusted-root <FILE>A Sigstore root you supply; defaults to the public root built into oyzu

The global options also apply.

The header says two separate things: whether the bundle's files check out, and whether the build it records succeeded. A failed build's bundle can still verify.

Inspect another bundle​

oyzu inspect path/to/downloaded/dist
oyzu inspect image.tar

For an OCI archive, the output shows its kind, platforms, size and digests.

Verify release provenance​

A passing inspection shows the files are intact. It doesn't show who built them. To check that, give oyzu inspect a saved Sigstore provenance bundle and a release profile describing the GitHub workflow and source you expect:

oyzu inspect app.tar.gz --provenance app.sigstore.json --release-profile expected-build.json
oyzu inspect dist --artifact app/linux/x86_64/app \
  --provenance app.sigstore.json --release-profile expected-build.json --json

For a bundle directory, also name the recorded file with --artifact. Verification runs offline against the saved evidence and never runs the artifact. The ordinary bundle checks run first, and any failure exits non-zero. With --json, the releaseVerification object reports the signature, subject and expectation results separately. A valid signature doesn't establish a SLSA level or permission to publish. See release provenance verification for the profile fields and limits.

JSON output​

oyzu --json inspect returns the full build-manifest record, the same document oyzu --json build prints, plus invocationId, runId, planDigest and envelopeDigest. See oyzu build JSON output.

Errors​

$ oyzu inspect nosuchdir
✗ COMMAND_FAILED: …\hello\nosuchdir does not exist; a bundle is the dist/ directory written by `oyzu build` or an exported OCI archive
  Next: Correct the reported cause and retry the command.

A missing dist/ names where Oyzu looked and suggests oyzu build. A file whose bytes no longer match its digest fails the check and exits non-zero.

oyzu history​

oyzu history [OPTIONS] [ID]
ArgumentMeaning
[ID]An invocation or run ID from a build's output

With no argument it lists retained builds, newest first. With an ID (from the Details line at the end of a build, or from the list) it prints a short summary of that build and where its files are. history has no options beyond the global options.

List builds​

Invocation evidence
Invocation / run             Outcome    Scope                  Started

44556-1792551937713942400-1  succeeded  1 targets · 1 actions  2026-10-21T03:05:40.216374700+00:00
…
  Next: oyzu history <ID> for a bounded summary and evidence paths
  Recorded observations; this summary does not verify artifact contents.

JSON output​

oyzu --json history returns an invocation-history record. Each entry in entries has the IDs, status, startedAt, target and artifact counts, action counts (reused, succeededNow, total), and the bundle and manifest paths, plus checks, tests, decisions, reuse, failures and diagnostics.

Errors​

$ oyzu history 1-2-3
✗ INVOCATION_NOT_FOUND: no retained bundle records this invocation; use oyzu history to see available evidence. Operations ending before a bundle is created and externally removed history are unavailable.

This exits 5. History only knows builds whose bundle is still on disk.

Exit status​

StatusWhen
0Listed, summarized or verified
1The bundle doesn't exist, a recorded file doesn't match its digest
5INVOCATION_NOT_FOUND for oyzu history ID
